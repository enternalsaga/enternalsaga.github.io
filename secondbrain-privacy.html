SecondBrain — Privacy Policy

SecondBrain is a private, single-user personal knowledge index. It is not a public product and has no other users besides its owner.

Gmail access (read-only)

SecondBrain requests the gmail.readonly OAuth scope for exactly one purpose: to index the owner's own Gmail messages (subject, sender, date, body text) into a private local database, so the owner can search their own mail history.

  • SecondBrain never sends, deletes, or modifies any Gmail message.
  • SecondBrain never shares Gmail data with any third party.
  • Indexed data is stored only in the owner's own local/private database and is never made public.
  • OAuth client credentials and access tokens are stored locally and are never transmitted anywhere except Google's own OAuth/Gmail API endpoints.
